## 密立根油滴实验 1.0

Windows 便携版，使用平衡电压加 0 V 下落法测量单颗油滴的电荷。

### 功能

- 导入本地视频，显示分辨率、帧率、帧数与时长。
- 给出 0 V 区间的建议值，可用 ±1 s 与 ±0.1 s 微调后确认。
- 在 0 V 起点 ±0.5 s 内框选一颗油滴，按 Trackpy 做局部跟踪。
- 逐帧复核完整轨迹；每次越过网格线或丢失身份都单独生成复核片段，可选择同一颗油滴或不同油滴。
- 计算单滴电荷：线性拟合下落速度，经 Cunningham 修正得到半径，再由平衡电压求 q，并按拟合斜率的不确定度传播 σq。
- 保留或排除测量记录；至少三条有效记录后可运行盲反演，输出 e 的估计值、标准不确定度、候选解、整数分配与残差。
- 导出会话，包含记录清单、反演结果与复核帧。

### 使用步骤

1. 选择视频，确认 0 V 区间。
2. 输入平衡电压，勾选确认后框选油滴。
3. 逐项复核过线片段，确认保留该条记录。
4. 重复测量；达到三条记录后，在「元电荷估计」中运行反演。
5. 关闭应用前导出会话。

### 说明

- 结果为实验测量值。σq 只包含速度拟合的随机项，不含仪器与物性参数误差。
- 三条记录的盲反演属于探索性结果，不构成电荷量子化的证明。
- 便携版未签名，首次运行可能出现 SmartScreen 提示。
- 下载后可用同名 `.sha256` 文件核对 EXE。
