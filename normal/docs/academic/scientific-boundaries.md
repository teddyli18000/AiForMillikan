# 科学边界与 AI 角色

## AI 辅助什么

Millikan AI 将“AI 赋能”限定为可审查的辅助：

- 从画面变化提出 0 V 边界建议；
- 检测网格与有效测量区域；
- 在用户框选附近运行局部 Trackpy；
- 生成 crossing 与整轨迹复核证据；
- 计算透明的拟合、q 和不确定度 trace；
- 对 accepted q 执行不使用参考元电荷的整数残差盲反演。

## 人必须确认什么

- 目标油滴在输入电压下是否平衡；
- 自动建议的 0 V 起止是否正确；
- 矩形框选的目标；
- crossing 前后是否仍为同一颗油滴；
- 单条 q 是否保留；
- diagnostic 或 rejected record 是否返回调整。

## 当前不能证明什么

- 程序不能自动证明目标确实达到力学平衡。
- 真实短视频验收不能代替仪器校准与独立重复测量。
- 当前 \(\sigma_q\) 只纳入速度拟合随机项，不是完整实验 uncertainty budget。
- 三条 q 只能产生探索性反演。
- 没有 continuous baseline 时不能宣称量子化模型胜出。
- `Experimental` 的 rule adapter 不是训练后的 ML 模型。

## 可复现性

可复现证据包括用户确认的时间、选择帧与矩形、轨迹表、crossing 结论、fit、参数、q、uncertainty budget、候选整数分配和残差。导出 session 使结果可以脱离 UI 复核。

## 面向课程实验的价值

项目的价值不是把实验包装为黑箱自动答案，而是把视频测量中容易被忽略的选择、失败与假设显式化。软件让学生能看到：

- 哪一帧和哪一颗油滴进入了计算；
- 轨迹在哪些位置丢失或重新捕获；
- 哪些 crossing 需要人工判断；
- q 如何由速度和参数得到；
- 哪些不确定度已经纳入；
- 元电荷候选如何由多个 q 的整数关系产生。
