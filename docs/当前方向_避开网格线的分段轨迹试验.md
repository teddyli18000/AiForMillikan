# 当前方向：避开网格线的分段轨迹试验

本文记录上游轨迹提取的当前研究方向。它用于统一接口假设和后续计划，不表示本分支已经实现新的检测、光流、Kalman、轨迹拼接或筛选算法。

## 老师建议原意

当前视频中网格线比油滴亮，网格线邻域容易造成误检、光流漂移和轨迹串号。老师建议先不要强行追踪油滴穿越网格线的全过程，而是主动把网格线附近区域当作不可靠区域：

```text
候选轨迹
→ 接近网格线邻域时切断
→ 保留未接触网格线的连续片段
→ 优先选择最长、运动最稳定的一段
→ 检查该段速度和位置是否可信
```

## 单段试验目标

当前先验证单段是否可靠，而不是直接完成 q 或 e 反演：

- 避开网格线后，误检和光流漂移是否明显减少；
- 单段速度拟合是否比跨网格强追踪更稳定；
- 最长连续段是否足以提供可靠终端速度；
- 网格线不可靠带宽度应设置多大；
- overlay 中该段是否能被人工复核。

## 关键边界

必须区分：

```text
一个连续轨迹片段
≠ 一个完整 q
≠ 一个独立的 e 反演样本
```

一个电压平台下的一段可靠轨迹只能估计一个速度 `v_i`。同一颗油滴至少需要两个不同电压平台下的可靠速度 `(U_i, v_i)` 才能计算一个 q。基本电荷盲反演需要多颗独立油滴的 `{q_i, sigma_q_i}`，不是很多轨迹片段。

## 未来多段关联

如果单段试验可行，上游后续可以研究网格线两侧片段是否属于同一颗油滴。可用证据包括：

- 网格线前片段向后的外推位置和速度；
- 网格线后片段向前的外推位置和速度；
- 有符号纵向速度和横向漂移；
- 油滴亮斑大小、亮度和形态；
- 时间间隔；
- 合理的最大速度变化或加速度范围。

这些属于上游研究，不在当前下游分支实现。

## 与下游物理模块的关系

第 4 步及之后的下游模块只读取上游已经接受的轨迹、平台、电压和标定尺度。无论轨迹来自全程连续追踪、避开网格线后的单段，还是未来上游完成的多段关联，下游都使用同一套：

```text
平台速度拟合
→ v = alpha - gamma U
→ Cunningham 半径
→ q 与不确定度
→ e 盲反演
```

当前不新增轨迹拼接 API，现有 `track_id / platform_id / time_s / y_px` 结构保持不变。
